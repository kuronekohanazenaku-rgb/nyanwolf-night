# にゃん狼ナイト（プレ版）

黒にゃんこと、秘密の人狼会。1台のスマートフォンを順番に回して遊ぶ、GMレスの対面人狼ゲームです。

## 遊ぶ

GitHub Pagesで公開するブラウザ版です。アカウント登録は不要です。iPhoneではSafariで開き、「共有」→「ホーム画面に追加」から起動しやすくできます。

1. 参加者名を入力し、役職の合計人数を合わせます。
2. 連続護衛と、決選投票後の同票処理を設定します。
3. 0日目は役職・初日の占い結果を確認し、全員が疑う相手を選びます。
4. 昼は対面で議論し、端末を回して投票します。同票なら同票候補だけで決選投票を1回行います。
5. 夜は本人だけが画面を開き、行動を選択します。占い結果は本人が確認するまで次へ進みません。

使用役職：人狼・狂人・市民・騎士・占い師・霊能者。

連続護衛は初期値「なし」。決選投票も同票なら、初期値「ランダム処刑」で、「処刑者を選ぶ」「処刑なし」に変更できます。

人狼の襲撃は、なんとなく襲う（1pt）／襲う（2pt）／積極的に襲う（3pt）から選び、その夜の対象別合計点で決まります。ポイントは毎夜リセットされます。

## 保存

参加者名、配役、行動とゲームの進行は、そのブラウザの端末内に保存します。GitHubへ送信する処理はありません。端末やブラウザを変えると引き継がれません。1つのタブで操作してください。

## ファイル

HTML・CSS・JavaScriptとオリジナルのSVG画像のみで動作します。パッケージのインストールやビルドは不要です。公開元は `main` ブランチのルートです。
